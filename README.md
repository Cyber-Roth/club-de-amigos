# Club de Amigos

## Descripción

Club de Amigos es una plataforma colaborativa para que niños puedan jugar, comunicarse y compartir actividades en un entorno seguro y supervisado por sus familias.

## Objetivo del MVP

Permitir que hasta cuatro niños puedan:

- verse mediante videollamada
- hablar entre ellos
- dibujar juntos
- jugar actividades colaborativas

desde cualquier dispositivo:

- PC
- Notebook
- Tablet
- Android
- iPhone
